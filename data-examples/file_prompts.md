# File Prompts

Use these as the `prompt` value when calling `run(prompt=..., result_file=...)`.

## dataset.json

Create a JSON file containing a compact customer support ticket dataset. Include a title, short description, and exactly 5 tickets. Each ticket must include id, customer, category, priority, subject, message, and expected_action.

## dataset.html

Create a complete standalone HTML file for a beginner 5K weekly training plan. It should include a title, a short subtitle, basic CSS, and a table with one row for each day of the week. Each row should include day, workout, duration, and notes.

## dataset.docx

Create a Word document project brief for an internal AI prompt evaluation tool. Include a title, overview, goals, deliverables, evaluation criteria, and next steps. Keep it concise and useful for a small engineering team.

## dataset.xlsx

Create an Excel workbook with quarterly sales data for testing spreadsheet evaluation. Include columns for Quarter, Product, Region, Units Sold, Revenue, and Notes. Include at least 8 realistic rows and a totals row.
